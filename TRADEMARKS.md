# Trademark Policy

The AGPL licence covers source code. It does not grant rights to the Exposure
Radar name, official logo, domains, or other project branding.

You may:

- truthfully state that software is based on or compatible with Exposure Radar;
- link to the official repository;
- use the name in reviews, tutorials, and community discussion.

You may not use project branding in a way that suggests an unofficial fork,
service, product, or organization is maintained, sponsored, or endorsed by the
official project.

Public forks and modified distributions should use a distinct name and logo,
while preserving copyright and licence notices required by the AGPL. Factual
phrases such as “based on Exposure Radar” remain welcome.

No registration symbol is claimed by this policy. Questions about branding use
can be raised with the maintainer through their GitHub profile.
